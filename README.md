### 🔭 SpectralFlow
**Distributed AI Observability Platform**

Architected a distributed platform monitoring LLM latency, token usage, cost, semantic drift, and runtime anomalies. Built a non-blocking, concurrent Go ingestion gateway with async event processing and a worker-pool architecture for high-throughput telemetry. Real-time analytics via TimescaleDB + Redis with EWMA-based anomaly detection, plus semantic drift detection using pgvector embeddings and cosine similarity.

`Go` `PostgreSQL` `TimescaleDB` `Redis` `pgvector` `Next.js` `LLMs`
